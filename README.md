## 🚀 How to Host on GitHub Pages for Free

Follow these simple steps to deploy your portfolio live at `https://<your-username>.github.io/harsh-portfolio/` (or `https://<your-username>.github.io/`):

### Option 1: Using Git via Terminal / Command Line

1. Initialize git and commit your files:
   ```bash
   cd "c:\Users\mishr\OneDrive\Desktop\harsh-portfolio"
   git init
   git add .
   git commit -m "Initial commit: Harsh Kumar Mishra portfolio"
   ```

2. Create a new public repository on GitHub named `harsh-portfolio` (or `<your-username>.github.io`).

3. Link your local repository to GitHub and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Harsh-Kumar-Mishra/harsh-portfolio.git
   git push -u origin main
   ```

4. Enable GitHub Pages:
   - On GitHub, go to your repository **Settings** → **Pages** (under the "Code and automation" section in the left sidebar).
   - Under **Build and deployment** → **Branch**, select `main` branch and `/ (root)` folder.
   - Click **Save**.
   - Within 1–2 minutes, your website will be live at:
     **`https://harsh-kumar-mishra.github.io/harsh-portfolio/`**
